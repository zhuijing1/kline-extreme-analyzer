# K线极值频率统计工具

> A股日内 5 分钟 K 线「最高价 / 最低价首次出现位置」的频率统计桌面工具。
> PyQt6 + pyqtgraph + AkShare/Baostock，Windows 免安装即用。

统计每个交易日**最高价 / 最低价首次出现在第几根 5 分钟 K 线**，并给出
「第 N 根 K 线收盘时，极值已出现」的累积概率——用来回答一个很具体的问题：

> **这只票今天的日内方向，通常在几点之前就定了？**

## 🚀 快速开始

- Windows 10/11
- Python 3.11+（本项目在 3.13 上开发）
- 依赖：`pip install -r requirements.txt`

### 启动

```bat
:: 方式 1：双击 启动程序.bat（cmd 窗口一闪而过）
```

2. 设置日期范围（最近 N 天 / 自定义）与分析参数
3. 点「开始分析」→ 看「关键数据统计」页

## 📐 指标定义

| 字段 | 含义 |
|---|---|
| `high_bar` | 当日最高价首次出现在第几根 5 分钟 K 线 |
| `low_bar` | 当日最低价首次出现在第几根 5 分钟 K 线 |
| `ext_bar` | `min(high_bar, low_bar)`——**先出现的那一个**极值 |
| 累积概率 `P(N)` | `P(ext_bar ≤ N)`，第 N 根收盘时极值已出现的概率 |
| 方向定型时点 | 累积概率首次达到 50% / 80% / 90% 的 K 线序号（T50 / T80 / T90） |

> ⚠️ `ext` 是「先出现的那一个」，**不是**「高低点都已出现」。后者需等 `max(high_bar, low_bar)`。

**随机基准**（48 根内极值均匀分布时）：`P(1) ≈ 2.1%`、`P(7) ≈ 14.6%`、`P(18) ≈ 37.5%`。
明显高于基线，才说明「极值集中在早盘」是真实规律。

### 性能约定（重要）

重依赖 **一律在函数内部延迟导入**，绝不在模块顶层写
`import pandas / numpy / pyqtgraph / akshare`：

- 顶层 import pandas ≈ 4s、numpy ≈ 2s、pyqtgraph ≈ 1.4s、akshare ≈ 6s
- 窗口出现时间：~8s → **~0.3s**
- 图表（pyqtgraph）在首次分析时才创建
- 股票列表预加载必须在后台线程，绝不能阻塞 GUI 线程

## 📝 数据来源与注意事项

- **A股 5 分钟 K 线**：Baostock 优先（稳定、导入快），AkShare 备用（3 次重试）
- 股票列表本地缓存 1 天（`.stock_list_cache.json`），后台线程静默刷新
- **口径提醒**：`P(N)` 是历史频率，**不是**未来的概率；涨跌停/一字板日（最高=最低=收盘）
  会显著抬高 `P(1)`，程序不会自动剔除，解读时请留意

更多见 [docs/数据分析指南.md](docs/数据分析指南.md)。
