# 数据分析指南 — 拿到极值频率数据之后该怎么用

本文回答一个问题：**程序跑出来的「第 N 根 K 线收盘时极值已出现的概率」，到底能推出什么结论、怎么落地、怎么避免自欺欺人。**

---

## 一、先搞清楚这几个数字的定义

| 字段 | 含义 |
|---|---|
| `high_bar` | 当日**最高价**首次出现在第几根 5 分钟 K 线 |
| `low_bar` | 当日**最低价**首次出现在第几根 5 分钟 K 线 |
| `ext_bar` | `min(high_bar, low_bar)` —— **先出现的那一个**极值出现在第几根 |
| 累积概率 P(N) | `P(ext_bar ≤ N)` = 到第 N 根 K 线收盘时，当天高低点中的第一个已经出现的概率 |
| 方向定型时点 | 累积概率首次达到 50% / 80% / 90% 的 K 线序号（程序已直接算好，报告首段 + 第一张卡片） |

### 三种模式分别回答什么问题

| 模式 | 回答的问题 | 典型用途 |
|---|---|---|
| **极值(最高或最低)** | 「今天的高低点，**先**出哪一个？多快出？」 | 判断日内方向**定型速度**——什么时候可以确认今天不再有反向风险 |
| **仅最高价** | 「今日最高价什么时候出现？」 | 找**尾盘拉升**型标的；高点形成规律 |
| **仅最低价** | 「今日最低价什么时候出现？」 | 找**尾盘杀跌**型标的；低点形成规律 |

> ⚠️ 口径提醒：`ext` 是「先出现的那一个」，**不是**「高低点都已出现」。两者都出现的时间要等 `max(high_bar, low_bar)`，程序目前没有这个统计，如果需要请另算。

## 二、标准读数流程（按这个顺序看）

### Step 1 — 先看样本量，不要急着看概率

报告第一行的「有效交易日 N」决定了这份数据能不能用：

| 有效交易日 | 结论可信度 |
|---|---|
| N < 30 | 只能定性参考，禁止据此下决策 |
| 30 ≤ N < 100 | 可用于描述，不可用于参数优化 |
| N ≥ 250 | 可用于构建规则并做样本外检验 |

**N 不等于你请求的天数**——「最近 N 天」是自然日，程序会自动过滤非交易日；停牌日也会被剔除。

### Step 2 — 看累积概率曲线的形状

打开 `📊 关键数据统计` → 下方「累积概率曲线」，三种典型形态：

| 形态 | 曲线特征 | 含义 |
|---|---|---|
| **阶跃型**（前陡后平） | 前几根陡升，之后走平 | 极值集中在早盘，日内方向早定型（多数大盘股） |
| **线性型** | 近似直线 | 极值均匀分布，无明显规律，这条线基本没信息量 |
| **凸型**（后段抬升） | 前段平缓，尾段陡升 | 极值集中在尾盘，典型于趋势日/消息面/尾盘异动 |

> 参考基准：若 48 根内极值完全均匀分布，则 P(1) ≈ 2.1%、P(7) ≈ 14.6%、P(18) ≈ 37.5%。
> **明显高于这条基线**才说明「早盘集中」是真的存在。

### Step 3 — 直接读「方向定型时点」（最有用的一行）

报告首段的 `P≥50% / P≥80% / P≥90%` 就是可执行结论：

> **「这只票的方向通常在 XX:XX 之前就基本定了。」**

- P≥50% 第 1 根（09:35）→ 开盘第一根 5 分钟 K 线就能定方向，**尾盘追单几乎没有意义**
- P≥90% 第 30 根（11:55）→ 上午临近收盘才定型，**属于慢热型，不适合日内抢跑**
- P≥50% 迟迟不出现 → 极值在盘中反复试探，属于**宽幅震荡型**，日内方向难判

### Step 4 — 比较「均值」与「中位数」

| 关系 | 分布特征 | 解读 |
|---|---|---|
| 均值 ≫ 中位数 | 右偏长尾 | 极值**多在早盘**，但偶尔拖到很晚（尾部风险） |
| 均值 ≈ 中位数 | 集中 | 极值出现时间很稳定 |
| 均值 ≪ 中位数 | 左偏 | 极值常在盘中后段才出现 |

### Step 5 — 三种模式横向对照（判断日内强弱结构）

| 组合 | 日内结构 | 交易含义 |
|---|---|---|
| ext 早 + high 晚 + low 早 | 先见低点、后见高点 | **先杀后拉**，偏强，早盘恐慌盘出尽 |
| ext 早 + high 早 + low 晚 | 先见高点、后见低点 | **先拉后杀**，偏弱，早盘诱多 |
| ext ≈ high ≈ low | 高低点同步出现 | 单边趋势日，趋势跟随有效 |
| high 远晚于 low | 高点集中在尾盘 | **尾盘拉升型**，适合隔夜/尾盘策略 |

### Step 6 — 与「日线涨跌概率」页联动

两张表配合，得到一个完整决策链：

```
日线涨跌概率（今日涨/跌的历史频率）
        ＋
日内极值概率（方向几点定型）
        ↓
「今日大概率上涨，且方向在 09:35 前已定型」
→ 早盘定型即可介入，尾盘不追
```

## 三、横向比较：把单只标的的统计变成选股/择时信号

对一批标的分别算出方向定型时点 T50，排序后就有两类用法：

1. **标的筛选**
   - T50 很早（开盘即定型）→ 波动集中在早盘 → 适合日内首段交易，**不适合尾盘追单**
   - T50 很晚（临近午盘/尾盘）→ 慢热型 → 适合趋势跟随、尾盘确认后入场
2. **时点过滤**：把某标的的历史 T50 作为「最早入场时间」的硬约束——例如某股历史 T50 稳定在第 7 根，则 10:05 之前不做多该股。

> 做这件事前先做**样本外检验**：用前 2/3 时间段选出规则，在后 1/3 时间段上验证，否则得到的几乎一定是过拟合结果。

## 四、必须避开的坑（这部分比结论本身更重要）

1. **样本重叠 / 市场状态单一**
   只取一个月的数据，结论其实只是「那个月的行情特征」。必须跨阶段采样：至少覆盖一年以上，且包含上涨、下跌、震荡三种状态。

2. **涨跌停 / 一字板污染样本**
   涨跌停日最高=最低=收盘价 → 极值「同时出现」，`ext_bar` 必然落在很小的序号上。这类日子会**大幅拉高** P(1)。程序目前没有自动剔除，请在选样时注意，或看「每日极值明细」里「极值类型 = 同时出现」的行数占比。

3. **复权口径**
   程序用前复权（AkShare `qfq` / Baostock `adjustflag=2`）。除权日的价格跳变可能造成「伪极值」，单日除权日的统计不可信。

4. **幸存者偏差**
   现在的股票列表回溯历史时，会漏掉已退市标的。个股结论影响不大，做行业/板块整体结论时要注意。

5. **P(N) 是历史频率，不是未来的概率**
   它描述的是「过去 N 个交易日里有多少比例出现过」，是**描述性**统计。把它当成预测概率直接下注，是这类工具最常见的误用。

6. **多重比较 / 挑参数**
   反复换检查点、换标的、换时段，直到找到一个「好看」的结论——这叫数据窥探（p-hacking）。正确做法：**先定规则，再看数据**，且必须留样本外区间。

7. **日内极值不含隔夜跳空**
   本工具只统计日内 5 分钟 K 线。真正的隔夜风险（跳空低开）要靠日线数据和「日线涨跌概率」页去看。

## 五、可落地的三种用法（举例）

### 用法 A — 尾盘不追单
某股历史 P(1)=80%、P(7)=95%（方向在 09:35 前就定型 80% 的时间）
→ **规则：09:35 后若价格仍在日内区间中部，说明方向已定，此时追单的赔率差。**

### 用法 B — 早盘介入的时间窗
某股 T50 = 第 4 根（09:50），T90 = 第 12 根（10:30）
→ **规则：09:50–10:30 是「方向从不确定变确定」的高质量介入窗口；10:30 后入场性价比下降。**

### 用法 C — 识别日内结构差的标的
「仅最高价」的 T50 明显晚于「仅最低价」的 T50
→ **该股常见「先杀后拉」，早盘的下跌往往是买点而不是卖点**（需结合日线涨跌概率确认）。

## 六、对应界面怎么用

| 你想看什么 | 去哪儿 |
|---|---|
| 方向几点定型 | `📊 关键数据统计` → **第一张卡片**「方向定型时点 P≥50%」 |
| 各检查点的累积概率 | 卡片行（每张卡 = 一个检查点） |
| 极值出现时间的分布 | 「极值出现频率分布」柱状图（横轴K线序号，纵轴天数；峰值=最常出现的位置） |
| 累积曲线形状 | 「累积概率曲线」（带 50% 参考虚线） |
| 分布是早是晚 | 分布图的**峰值横坐标** |
| 逐日核对 | `📋 每日极值明细` → 每行含最高/最低价、各自出现的K线序号与时刻、极值类型 |
| 防止程序算错 | 报告末段「核对用」列出每个检查点命中的**具体日期**，可人工抽查 |
| 今日涨跌倾向 | `📈 日线涨跌概率` 页 |

## 七、把结论写下来的标准格式

```
标的：600519 贵州茅台
样本：2026-08-25 ~ 2026-10-21，36 个交易日
模式：极值(最高或最低)
方向定型：P≥50% 第1根(09:35)，P≥90% 第4根(09:50)
含义：该股日内高低点中的第一个，80% 集中在开盘第一根 5 分钟 K 线内出现；
      09:50 之后方向基本无悬念，尾盘追单赔率差。
局限：样本仅 36 天且集中在同一市场阶段；未剔除涨跌停样本；
      结论为描述性统计，不能直接当作未来概率使用。
```
