# K线极值频率统计工具 — v3 重构概览

## 完成时间
2026-10-22

## v3 变更（本次重构）

### 1. 启动速度
| | v2 | v3 |
|---|---|---|
| 窗口出现 | ~8s（pandas 4.1s + numpy 1.8s + pyqtgraph 1.4s + akshare 6.2s 阻塞 GUI 线程） | **~0.3s** |
| 股票列表预加载 | GUI 线程，卡界面 | 后台线程 |
| 图表创建 | 启动时即建 | 首次分析时按需创建 |

根因：模块顶层 import 重依赖 + `QTimer.singleShot(500, preload_stock_cache)` 在 GUI 线程执行。

### 2. 模块拆分（单文件 2104 行 → 3 个模块）
- `kline_data.py` — 数据层：搜索 / 缓存 / 5分钟K线 / 日线
- `kline_stats.py` — 统计引擎：纯计算，无 GUI 依赖，可独立单测
- `kline_extreme_analyzer.py` — GUI 主程序

### 3. 窗口体验
- **无控制台窗口**：`启动程序.vbs` / `启动程序.bat` / 桌面快捷方式 全部走 `pythonw.exe`；
  `调试启动.bat` 保留控制台供排错
- **任务栏图标 = 桌面图标**：调用 `SetCurrentProcessExplicitAppUserModelID` + `setWindowIcon`；
  图标重做为 16/24/32/48/64/128/256 七档（原来只有 16x16）
- 新增「方向定型时点 T50/T80/T90」：累积概率首次达到 50%/80%/90% 的 K 线序号，
  直接出现在第一张卡片与报告首段

### 4. 清理与合并
- 5 个零散测试脚本 → 合并为 `test_all.py`（含离线单元测试 + `--online` 联网测试）
- 清理残留垃圾文件 `nul`（Windows 保留设备名，已用 `\\?\` 前缀成功删除）

### 5. 顺手修的 Bug
- Baostock 时间字段解析：改用 `time.str.slice(0,14)` + `%Y%m%d%H%M%S`，
  不再依赖 pandas 对 `%f` 位数的宽容解析
- `search_stocks` 纯 6 位代码走快速路径，不再先加载全量列表
- 缓存过期判断拆分为 `is_stock_cache_fresh()`，后台线程据此决定是否联网

## 保留功能
- 三种分析模式（极值 / 仅最高 / 仅最低），切换无需重新取数
- 自定义检查点累积概率
- 日线涨跌概率 Tab（涨/跌/平、最大连涨连跌、按星期统计）
- 深色交易终端主题、结果页双层 Tab、文字统计报告
