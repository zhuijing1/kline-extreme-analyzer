# K线极值频率统计工具 — 使用说明

统计 A 股日内 5 分钟 K 线中**最高价 / 最低价首次出现的位置频率**，
并给出「第 N 根 K 线收盘时极值已出现」的累积概率。

---

## 快速开始

三种启动方式，**都不会弹出 cmd 窗口**：

| 方式 | 说明 |
|---|---|
| 桌面快捷方式 `K线极值分析` | 推荐。直接指向 `pythonw.exe`，图标与任务栏一致 |
| `启动程序.vbs` | 双击即可，完全无控制台窗口 |
| `启动程序.bat` | 双击即可，cmd 窗口一闪而过（用 `start` 立即关闭） |
| `调试启动.bat` | **保留**控制台窗口，出错时看日志用 |

启动后：输入代码或名称（如 `600519` / `贵州茅台`）→ 点「搜索」→ 下拉选择标的
→ 设置日期范围与分析参数 → 点「开始分析」。

> 启动无需等待：重依赖（pandas / pyqtgraph）全部在后台预热，窗口秒开（约 0.3s）。

## 程序位置

程序装在 **DSH 工作区**的 `K线极值统计工具` 文件夹里（本机实际路径
`D:\dsh\dsh\K线极值统计工具`）。

- 整个文件夹可以随意复制到别的机器/别的目录，程序不依赖固定路径
  （股票列表缓存、图标都是相对脚本目录定位的）
- 唯一的外部依赖是 Python 解释器路径，写死在 `启动程序.bat` / `启动程序.vbs` /
  `创建快捷方式.py` 里，换机器时改这三处即可
- 桌面路径如果被重定向（本机桌面在 `D:\desktop`），快捷方式会自动落到真实桌面

## 窗口与任务栏图标

程序图标为 `kline_analyzer.ico`（16/24/32/48/64/128/256 七档）：

- 桌面快捷方式图标 = 该 ico
- 窗口标题栏 / 任务栏图标 = 同一 ico

实现方式：程序启动时调用 `SetCurrentProcessExplicitAppUserModelID`（Windows 专用），
再 `setWindowIcon()`。**不设 AppUserModelID 的话，任务栏会显示 python.exe 的图标。**

图标重新生成：`python 创建图标.py`
快捷方式重建/修复：`python 创建快捷方式.py` 或 `powershell -ExecutionPolicy Bypass -File 更新图标.ps1`

## 数据规格

- 每日固定 **48 根** 5 分钟 K 线（上午 24 根 09:35–11:30 + 下午 24 根 13:05–15:00）
- 数据源：**Baostock 优先**（匿名登录、稳定、导入快），**AkShare 备用**（东方财富，3 次重试），
  失败自动降级；两个源均为**前复权**口径，见 [README 数据源一节](../README.md#-数据源)
- 股票列表本地缓存 1 天（`.stock_list_cache.json`），后台线程静默刷新

## 分析模式

| 模式 | 说明 |
|---|---|
| **极值(最高或最低)** | 任一极值首次出现即算，反映日内方向形成速度 |
| **仅最高价** | 只看当日最高价何时出现 |
| **仅最低价** | 只看当日最低价何时出现 |

三种模式切换**无需重新获取数据**。

## 自定义检查点

在「检查点K线」输入框用逗号分隔，如 `1,7,18,24,36`。
程序会计算每个检查点收盘时极值已出现的累积概率。默认 `1,7,18`。

## 日期范围

- **最近 N 天**：从今天往前推 N 个自然日（自动过滤非交易日）
- **自定义**：精确指定起止日期

---

## 注意事项

1. 首次搜索需联网刷新股票列表（后台进行，约 10–30 秒），之后走本地缓存秒出
2. Baostock 单次查询有区间上限，超长区间请分批
3. 报告中的「日期」指交易日；A 股交易日与自然日历一致（周末节假日除外）

### 性能约定

重依赖（pandas / numpy / pyqtgraph / akshare）**一律在函数内部延迟导入**：

- GUI 启动路径只加载 PyQt6 → 窗口约 **0.3 秒**出现
- pyqtgraph 图表在首次分析时才创建
- 股票列表预加载在后台线程执行，缓存有效时完全不联网

新增数据源或新功能时请保持这一约定：不要在模块顶层 `import pandas / numpy / pyqtgraph / akshare`。
